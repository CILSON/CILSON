## 🚀 Featured Project

### TerminalX — Financial Intelligence Terminal

<p align="center">
  <img src="https://raw.githubusercontent.com/CILSON/TERMINALX/main/frontend/public/terminalx-dashboard.png" width="100%" alt="TerminalX Dashboard"/>
</p>

**TerminalX** is a Bloomberg-inspired financial terminal built with **Next.js, React, TypeScript, Python, and FastAPI**.

It combines:

* 📈 Market data and market heatmaps
* 🤖 AI-powered financial analysis
* 📰 Financial news
* 📅 Economic calendar
* ⚡ Real-time WebSocket communication
* ⌨️ Keyboard-driven navigation
* 🖥️ Dense terminal-style interface

**Tech:** `Next.js` · `React` · `TypeScript` · `Python` · `FastAPI` · `Zustand` · `WebSockets`

👉 [View TerminalX](https://github.com/CILSON/TERMINALX)
